Mathematical Closed-Loop Advisory Control Formulation

The ARM Cortex-R5 real-time core evaluates image sharpness $Q_{ ext{blur}}(t)$ using the Variance of Laplacian ($ ext{VoL}$) calculated in FPGA logic:

Q_blur(t) = Var(∇² I(t)) = (1 / N) * Σ_(x,y) [ L(x,y) - L_mean ]²

Where $L(x,y) = rac{\partial^2 I}{\partial x^2} + rac{\partial^2 I}{\partial y^2}$ is computed via a $3 imes3$ spatial convolution matrix on streaming pixels. The advisory velocity command $\mathbf{v}_{ ext{adv}}(t)$ sent over MAVLink is governed by:

v_adv(t) = v_nominal * max( γ_min, 1 - α * ReLU( 1 - Q_blur(t) / Q_target ) )

Where $lpha$ is the velocity throttling gain, $Q_{ ext{target}}$ is the required sharpness threshold, and $\gamma_{ ext{min}} = 0.2$ ensures safe aerodynamic flight speed.
